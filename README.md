# MadLib Project
It is a project that collects inputs from the user and tells a story based on the inputs collected.

# ABOUT
This project collects inputs from the user and prints a story with those inputs. Since the user has no idea what the story is all about or how it is structured, the story ends up being grammatically correct but mostly completely makes no sense.

# How to run it
Since this is a simple project, it can be run in the terminal of the code editor. Make sure you have python installed on your computer then run madLib.py.

# What it does
It takes input from the user and since there are two options, the story printed out will depend on the user's choice.

# What I learned
I learned how to use inputs and conditionals while paying attention to data types.

# Technologies used
Pycharm and Python.
